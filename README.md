# Informativa sulla Privacy - Lectio
Ultimo aggiornamento: 2026

L'applicazione Lectio rispetta la privacy degli utenti. 
- Non raccogliamo né conserviamo dati personali identificativi su server esterni.
- Eventuali dati elaborati dall'applicazione (come note, registrazioni audio o trascrizioni) rimangono memorizzati localmente sul dispositivo dell'utente, salvo ove diversamente indicato o sincronizzato tramite iCloud personale dell'utente.
- Non condividiamo alcun dato con soggetti terzi per scopi commerciali o di marketing.
